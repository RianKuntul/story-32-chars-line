A single Wi-Fi network name of at most 32 characters that lands a joke and implies a whole story — a passer-by reading it in their phone's network list gets the setup, the twist, and the ending in one line.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): one line, 1–32 characters, no trailing newline.
